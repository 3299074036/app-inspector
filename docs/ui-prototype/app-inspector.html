功能实现边界

应用发现

使用 PackageManager.getInstalledApplications()。Android 11+ 在清单中声明 QUERY_ALL_PACKAGES 会受到应用商店审核限制；若不公开上架，可用于设备工具。

“已删除”定义

PackageManager 无法直接列出已彻底卸载的应用。正式版需在本地保存扫描快照，与当前列表做差异比对；仅显示 App Inspector 曾经扫描到、之后消失的项目。

“已停用”识别

综合 ApplicationInfo.enabled 与组件启用状态判断。系统应用与用户应用通过 FLAG_SYSTEM / FLAG_UPDATED_SYSTEM_APP 区分。

APK 大小与拆分包

统计 sourceDir 和 splitSourceDirs。提取时保留所有 split，避免只导出 base.apk 后无法复原安装。

导出

Markdown / TXT 使用流式写入；XLSX 建议 Apache POI SXSSF。统一从当前查询快照生成，防止导出过程中应用列表变化。

权限与发布

优先使用 Storage Access Framework，不申请“所有文件访问”权限。若计划上架 Google Play，需要先确认“已安装应用清单”是否属于核心功能并准备权限声明。
